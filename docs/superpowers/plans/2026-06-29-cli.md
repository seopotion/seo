# @seo/cli Management CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `tsx`-run management CLI (`@seo/cli`) at `apps/cli` with `infra check` and `db init` commands, structured `Result`/exit codes, and a text/json dual-output emitter for both humans and AI agents.

**Architecture:** A new `apps/cli` npm workspace using `citty`. Thin `commands/` parse args, create an emitter, lazy-import a `lib/` function that returns `Result<T>`, render it, and `process.exit()` with an `EXIT` code. `lib/` holds all logic and is unit-tested; `@shared/db` is the client layer. Output goes through an `Emitter` with `text` (human, ANSI to stderr, result to stdout) and `json` (JSONL to stderr, final JSON to stdout) modes.

**Tech Stack:** TypeScript 6, citty, tsx, `@shared/db`, `@aws-sdk/client-sqs`, Vitest 4, Biome.

## Global Constraints

- Run via `tsx`/Node, **never** bun. No `bin` field / no installed executable.
- Biome style: single quotes, 2-space indent, 100-char width, organized imports. Run `npm run lint:fix` on new files.
- `verbatimModuleSyntax`: use `import type` / `export type` for type-only imports.
- Tests live ONLY under `apps/cli/tests/**/*.test.ts` (vitest glob). No colocated `src/*.test.ts`.
- No per-app `tsconfig.json` — the root `tsconfig.json` already includes `apps/*/src/**` and `apps/*/tests/**`.
- Internal workspace deps use `"*"` (no `workspace:` protocol).
- `lib/` functions return `Result<T>` and never call `process.exit` or print. Only `commands/` do I/O + exit.
- Always-green gates before "done": `npm run lint`, `npm run check`, `npm test`.
- Work happens on the existing `cli` branch.

/**
 * Core types for the seo CLI.
 *
 * Every lib function returns Result<T>. Errors are structured and
 * machine-readable. Commands translate Results into output + exit codes.
 */

export interface CliError {
  code: string;
  message: string;
  suggestion?: string;
}

export type Result<T> = { ok: true; data: T } | { ok: false; error: CliError };

export const ok = <T>(data: T): Result<T> => ({ ok: true, data });
export const fail = (code: string, message: string, suggestion?: string): Result<never> => ({
  ok: false,
  error: { code, message, suggestion },
});

export const EXIT = {
  SUCCESS: 0,
  USER_ERROR: 1,
  INFRA_DOWN: 2,
  OP_FAILED: 3,
  INTERNAL: 4,
} as const;
export type ExitCode = (typeof EXIT)[keyof typeof EXIT];

export type OutputMode = 'text' | 'json';

export interface Emitter {
  step(name: string, status: 'start' | 'done' | 'fail', detail?: string): void;
  info(message: string): void;
  warn(message: string): void;
  error(message: string): void;
  result<T>(data: Result<T>): void;
}

export type InfraService = 'mongo' | 'sqs' | 'api';

export interface ServiceCheck {
  service: InfraService;
  available: boolean;
  latencyMs?: number;
  error?: string;
}

export interface InfraCheckResult {
  allHealthy: boolean;
  services: ServiceCheck[];
}

export interface DbInitData {
  collections: string[];
}
```

/**
 * Output emitter — abstracts text (human) vs json (agent) rendering.
 *
 * text: progress to stderr, final result pretty-printed to stdout.
 * json: JSONL progress events to stderr, single final JSON object to stdout.
 */
import type { Emitter, OutputMode } from '../types';

export function createEmitter(mode: OutputMode): Emitter {
  return mode === 'json' ? createJsonEmitter() : createTextEmitter();
}

function createTextEmitter(): Emitter {
  return {
    step(name, status, detail) {
      const icon = status === 'start' ? '▶' : status === 'done' ? '✓' : '✗';
      process.stderr.write(`${detail ? `${icon} ${name}: ${detail}` : `${icon} ${name}`}\n`);
    },
    info(message) {
      process.stderr.write(`  ${message}\n`);
    },
    warn(message) {
      process.stderr.write(`⚠ ${message}\n`);
    },
    error(message) {
      process.stderr.write(`✗ ${message}\n`);
    },
    result(data) {
      if (!data.ok) {
        process.stderr.write(`\nError [${data.error.code}]: ${data.error.message}\n`);
        if (data.error.suggestion) {
          process.stderr.write(`  Suggestion: ${data.error.suggestion}\n`);
        }
      } else {
        process.stdout.write(`${JSON.stringify(data.data, null, 2)}\n`);
      }
    },
  };
}

function createJsonEmitter(): Emitter {
  const jsonLine = (obj: Record<string, unknown>) => {
    process.stderr.write(`${JSON.stringify(obj)}\n`);
  };
  return {
    step(name, status, detail) {
      jsonLine({ type: `step:${status}`, step: name, ...(detail ? { detail } : {}) });
    },
    info(message) {
      jsonLine({ type: 'info', message });
    },
    warn(message) {
      jsonLine({ type: 'warn', message });
    },
    error(message) {
      jsonLine({ type: 'error', message });
    },
    result(data) {
      if (data.ok) {
        process.stdout.write(`${JSON.stringify(data.data)}\n`);
      } else {
        process.stdout.write(`${JSON.stringify({ error: data.error })}\n`);
      }
    },
  };
}
```

/**
 * Infrastructure health checks. Each probe returns a ServiceCheck; checkInfra
 * aggregates them. Pure of process I/O — returns a Result for the command layer.
 */
import { GetQueueAttributesCommand, SQSClient } from '@aws-sdk/client-sqs';
import { closeDb, getDb } from '@shared/db';
import { type InfraCheckResult, type InfraService, ok, type Result, type ServiceCheck } from '../types';

export const VALID_SERVICES: InfraService[] = ['mongo', 'sqs', 'api'];

async function checkMongo(): Promise<ServiceCheck> {
  const start = Date.now();
  try {
    const db = await getDb();
    await db.command({ ping: 1 });
    return { service: 'mongo', available: true, latencyMs: Date.now() - start };
  } catch (e) {
    return { service: 'mongo', available: false, error: (e as Error).message };
  }
}

async function checkSqs(): Promise<ServiceCheck> {
  const start = Date.now();
  const queueUrl = process.env.SCAN_QUEUE_URL;
  if (!queueUrl) {
    return { service: 'sqs', available: false, error: 'SCAN_QUEUE_URL not set' };
  }
  const endpoint = process.env.SQS_ENDPOINT;
  const client = new SQSClient(
    endpoint
      ? { endpoint, region: 'elasticmq', credentials: { accessKeyId: 'local', secretAccessKey: 'local' } }
      : {},
  );
  try {
    await client.send(
      new GetQueueAttributesCommand({ QueueUrl: queueUrl, AttributeNames: ['ApproximateNumberOfMessages'] }),
    );
    return { service: 'sqs', available: true, latencyMs: Date.now() - start };
  } catch (e) {
    return { service: 'sqs', available: false, error: (e as Error).message };
  } finally {
    client.destroy();
  }
}

async function checkApi(): Promise<ServiceCheck> {
  const start = Date.now();
  const url = `${process.env.API_URL ?? 'http://localhost:8787'}/health`;
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), 3000);
  try {
    const res = await fetch(url, { signal: controller.signal });
    if (!res.ok) {
      return { service: 'api', available: false, error: `HTTP ${res.status}` };
    }
    return { service: 'api', available: true, latencyMs: Date.now() - start };
  } catch (e) {
    return { service: 'api', available: false, error: (e as Error).message };
  } finally {
    clearTimeout(timer);
  }
}

const CHECKS: Record<InfraService, () => Promise<ServiceCheck>> = {
  mongo: checkMongo,
  sqs: checkSqs,
  api: checkApi,
};

export async function checkInfra(
  services: InfraService[] = VALID_SERVICES,
): Promise<Result<InfraCheckResult>> {
  const checked = await Promise.all(services.map((s) => CHECKS[s]()));
  await closeDb(); // release the shared Mongo client so the CLI can exit
  return ok({ allHealthy: checked.every((c) => c.available), services: checked });
}
```

/**
 * infra command — local infrastructure health checks.
 */
import { defineCommand } from 'citty';
import { type InfraService, EXIT, fail, type OutputMode } from '../types';
import { createEmitter } from '../utils/emitter';
import { outputOption, verboseOption } from './shared';

export const infraCommand = defineCommand({
  meta: { name: 'infra', description: 'Infrastructure management' },
  subCommands: {
    check: defineCommand({
      meta: { name: 'check', description: 'Check infrastructure health (mongo, sqs, api)' },
      args: {
        ...outputOption,
        ...verboseOption,
        services: {
          type: 'string',
          description: 'Comma-separated services to check: mongo,sqs,api',
        },
      },
      async run({ args }) {
        const emitter = createEmitter(args.output as OutputMode);
        const { VALID_SERVICES, checkInfra } = await import('../lib/infra');

        let services: InfraService[] | undefined;
        if (args.services) {
          const requested = (args.services as string).split(',').map((s) => s.trim());
          const invalid = requested.filter((s) => !VALID_SERVICES.includes(s as InfraService));
          if (invalid.length > 0) {
            emitter.result(
              fail(
                'INVALID_SERVICE',
                `Unknown service(s): ${invalid.join(', ')}`,
                `Valid: ${VALID_SERVICES.join(', ')}`,
              ),
            );
            return process.exit(EXIT.USER_ERROR);
          }
          services = requested as InfraService[];
        }

        const result = await checkInfra(services);

        if (args.output !== 'json' && result.ok) {
          for (const svc of result.data.services) {
            const icon = svc.available ? '✓' : '✗';
            const latency = svc.latencyMs !== undefined ? ` (${svc.latencyMs}ms)` : '';
            const error = svc.error ? ` — ${svc.error}` : '';
            emitter.info(`${icon} ${svc.service.padEnd(6)}${svc.available ? 'up' : 'down'}${latency}${error}`);
          }
          emitter.info('');
          emitter.info(result.data.allHealthy ? 'All services healthy' : 'Some services unavailable');
        } else {
          emitter.result(result);
        }

        process.exit(result.ok && result.data.allHealthy ? EXIT.SUCCESS : EXIT.INFRA_DOWN);
      },
    }),
  },
});
```

/**
 * Database management. initDb wraps ensureIndexes() (the `db:init` script's
 * logic) behind the Result contract.
 */
import { closeDb, ensureIndexes } from '@shared/db';
import { type DbInitData, fail, ok, type Result } from '../types';

export async function initDb(): Promise<Result<DbInitData>> {
  try {
    await ensureIndexes();
    return ok({ collections: ['users', 'orgs'] });
  } catch (e) {
    return fail(
      'DB_INIT_FAILED',
      (e as Error).message,
      'Is MongoDB running? Try `docker compose up -d mongo`.',
    );
  } finally {
    await closeDb();
  }
}

  subCommands: {
    init: defineCommand({
      meta: { name: 'init', description: 'Create MongoDB indexes (ensureIndexes)' },
      args: { ...outputOption, ...verboseOption },
      async run({ args }) {
        const emitter = createEmitter(args.output as OutputMode);
        const { initDb } = await import('../lib/db');

        emitter.step('db:init', 'start');
        const result = await initDb();
        emitter.step('db:init', result.ok ? 'done' : 'fail');
        emitter.result(result);

        process.exit(result.ok ? EXIT.SUCCESS : EXIT.OP_FAILED);
      },
    }),
  },
});

## Notes for the implementer

- **citty version behavior:** `runMain` handles `--help`/`--version` and prints usage. If `citty@^0.1.6` resolves differently, keep the `defineCommand`/`runMain` shape; the API has been stable across 0.1.x.
- **Why `closeDb()` in lib:** `getDb()` caches a Mongo client at module scope for Lambda warm-reuse. A short-lived CLI must release it (or the event loop lingers until `process.exit`). Calling `closeDb()` in `checkInfra`/`initDb` keeps shutdown clean and is safe when no connection was opened.
- **Do not** add a `bin` field or a per-app `tsconfig.json`.
- If `npm run check` ever misses `apps/cli`, confirm the root `tsconfig.json` `include` still has `apps/*/src/**/*` and `apps/*/tests/**/*`.
